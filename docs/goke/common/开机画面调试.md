# uboot 开机画面使用说明

### 1. 先集成提供的 uboot 屏幕驱动

### 2. 修改 bootcmd

原来的 bootcmd
```
xmediaapp;sf probe 0;sf read 0x40FFFFC0 0x50000 0x400000;bootm 0x40FFFFC0
```

加入命令后的 bootcmd
```
sf probe 0;sf read 0x46B50000 0xB50000 0x70800;lcd_st7701s_init;initvo;startvo 0 18;startvl 0 0x46B50000 480 0 0 480 640;xmediaapp;sf read 0x40FFFFC0 0x50000 0x400000;bootm 0x40FFFFC0
```

命令说明

1. `sf read 0x46B50000 0xB50000 0x70800` -> 从 flash 指定地址读取 yuv 数据到内存指定地址，0xB50000 为 flash 指定地址，0x46B50000 为内存指定地址，0x70800 为数据长度；

2. `lcd_st7701s_init` -> spi 初始化屏幕；

3. `initvo` -> 初始化 vo；

4. `startvo 0 18` -> 根据屏幕参数启动 vo；

5. `startvl 0 0x46B50000 480 0 0 480 640` -> vo 从内存指定地址读取数据并输出；

6. 0x46B50000 为内存指定地址，约束和 `/proc/umap/media-mem` 中的 `VO(0)_LayerBuf` 使用的物理地址相同，不然该内存地址被踩时会花屏；

   ```
   |-MMB: phys(0x46B50000, 0x471A1FFF), kvirt=0x00000000, flags=0x00000000, length=1352KB,    name="VO(0)_LayerBuf"
   ```
