# 文件系统分区参考

以调整 rootfs 分区大小，创建 usr、data、appfs 分区，并将原来 rootfs 中的 usr 文件夹移动到 usr 分区为例。

请根据项目实际情况自行调整 ！！！

## 1. 去掉 rootfs 的 /usr

source/rootfs/busybox/Makefile

在 `cp -arf $(BUSYBOX_PREFIX)/. $(ROOTFS_PREFIX) ` 后面一句

`rm -rf $(ROOTFS_PREFIX)/usr`



## 2. 修改 bootargs

configs/xm72050510/prebuildts/spi_bootargs_tiny.txt

`bootargs` 修改分区大小`512K(boot),512K(bootargs),4M(kernel),2M(rootfs),512K(usr),512K(data),-(appfs)`

完整修改：

```
bootcmd=sf probe 0;xmediaapp;boothz 0x41000000 0x40008000 0x20000 0x240000
bootargs=mem=128M console=ttyAMA0,115200 root=/dev/mtdblock3 rootfstype=jffs2 rw mtdparts=sfc:128K(boot),128K(bootargs),2304K(kernel),2M(rootfs),512K(usr),512K(data),-(appfs) lpj=9838592
```



## 3. 修改烧录 xml

拷贝一份 spi_partitions_tiny.xml，在 FastBurn 中加入和调整自定义分区信息，比如：

```
<?xml version="1.0" encoding="utf-8" ?>
<Partition_Info>
    <Part Select="1" PartName="fastboot" StorageMedia="ddr" ImageFormat="raw" StartAddr="0" PartLen="0" ImagePath="out\xm72050510\image\spi_image\bootstrap_xm72050510.bin" />
    <Part Select="1" PartName="boot" StorageMedia="spi-nor" ImageFormat="raw" StartAddr="0" PartLen="128K" ImagePath="out\xm72050510\image\spi_image\uboot_xm72050510.bin" />
    <Part Select="1" PartName="bootargs" StorageMedia="spi-nor" ImageFormat="raw" StartAddr="128K" PartLen="128K" ImagePath="out\xm72050510\image\spi_image\bootargs.bin" />
    <Part Select="1" PartName="kernel" StorageMedia="spi-nor" ImageFormat="raw" StartAddr="256K" PartLen="2304K" ImagePath="out\xm72050510\image\spi_image\kernel_xm72050510" />
    <Part Select="1" PartName="rootfs" StorageMedia="spi-nor" ImageFormat="jffs2" StartAddr="2560K" PartLen="2M" ImagePath="out\xm72050510\image\spi_image\rootfs.64k.jffs2" />
    <Part Select="1" PartName="usr" StorageMedia="spi-nor" ImageFormat="jffs2" StartAddr="4608K" PartLen="512K" ImagePath="out\xm72050510\image\spi_image\usrfs.jffs2" />
    <Part Select="1" PartName="data" StorageMedia="spi-nor" ImageFormat="jffs2" StartAddr="5M" PartLen="512K" ImagePath="out\xm72050510\image\spi_image\datafs.jffs2" />
    <Part Select="1" PartName="appfs" StorageMedia="spi-nor" ImageFormat="jffs2" StartAddr="5632K" PartLen="10752K" ImagePath="out\xm72050510\image\spi_image\appfs.jffs2" />
</Partition_Info>
```



## 4. 创建分区 image

```
# 创建分区 image 目录
mkdir -p out/xm72050510/usrfs
mkdir -p out/xm72050510/datafs
mkdir -p out/xm72050510/appfs

# 拷贝内容到分区目录
cp -r out/xm72050510/rootfs_builddir/busybox-1_26_2/.install/usr/* out/xm72050510/usrfs/

# 创建 jffs2 分区 image
mkfs.jffs2 -d out/xm72050510/usrfs/ -l -e 0x10000 -o out/xm72050510/image/spi_image/usrfs.jffs2
mkfs.jffs2 -d out/xm72050510/datafs/ -l -e 0x10000 -o out/xm72050510/image/spi_image/datafs.jffs2
mkfs.jffs2 -d out/xm72050510/appfs/ -l -e 0x10000 -o out/xm72050510/image/spi_image/appfs.jffs2
```



## 5. 板端启动脚本挂载

将下面内容加入开机启动脚本

```
mkdir -p /appfs
mkdir -p /data
mkdir -p /usr
mount -t jffs2 /dev/mtdblock4 /usr/
mount -t jffs2 /dev/mtdblock5 /data/
mount -t jffs2 /dev/mtdblock6 /appfs/
```



## *如果要修改 uboot 和 bootargs 分区大小

要修改source/bootloader/u-boot-2020.01/configs/xm720xxx_tiny_defconfig 的 `CONFIG_ENV_OFFSET`
```
CONFIG_ENV_OFFSET=0x20000
```
