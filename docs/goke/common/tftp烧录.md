## 2. 7606 系列

默认分区文件

uboot

```
mw 0x40080000 0xff 0x80000
tftpboot uboot.bin
sf probe 0;sf erase 0x0 0x80000;sf write 0x40080000 0x0 0x80000
```

bootargs

```
mw 0x40080000 0xff 0x40000
tftpboot bootargs.bin
sf probe 0;sf erase 0x80000 0x40000;sf write 0x40080000 0x80000 0x40000
```

bl31

```
mw 0x40080000 0xff 0x40000
tftpboot bl31
sf probe 0;sf erase 0xC0000 0x40000;sf write 0x40080000 0xC0000 0x40000
```

kernel

```
mw 0x40080000 0xff 0x400000
tftpboot kernel
sf probe 0;sf erase 0x100000 0x400000;sf write 0x40080000 0x100000 0x400000
```

rootfs

```
mw 0x40080000 0xff 0xB00000
tftpboot rootfs.64k.jffs2
sf probe 0;sf erase 0x500000 0xB00000;sf write 0x40080000 0x500000 0xB00000
```
