## 一、板端调试常用命令

### 设置 IP

#### 设置网卡 mac

```
ifconfig eth0 hw ether 82:EF:8F:FF:87:CB
```

#### 设置网卡 ip 和 route

```
ifconfig eth0 192.168.145.122 netmask 255.255.255.0 up
route add default gw 192.168.145.254
```

### 挂载 nfs

```sh
mount -t nfs -o nolock 192.168.146.201:/home/huangmingle /nfsroot
```

```
mount -t nfs -o nolock,addr=192.168.143.40 -o tcp 192.168.143.40:/home/miller /nfsroot
```

### 挂载 SD 卡

```sh
mount -t vfat /dev/mmcblk0p1 /mnt
```

### 加载驱动

```sh
./load xm72050200 -i sensor0 gc2063 -osmem 32
```

```
./load xm7206v11a -i -osmem 32
```

### 监控内存

```
watch -n 1 'grep -A 2 "Inactive" /proc/meminfo '
```

### 测试磁盘速度

```
dd if=/dev/zero of=/sd/testfile bs=64K count=1600
```

```
dd if=/dev/zero of=/dev/mmcblk1p1 bs=64K count=1600
```

### 查看进程中线程资源情况

```sh
top -H -p `pidof multi_thread`
```

> [!NOTE]
>
> *线程要通过 pthread_setname_np 设置名称*

## 二、板端调试常用脚本

### 7206v1/7606v1

```
#!/bin/sh

# config network
ifconfig eth0 192.168.145.122 netmask 255.255.255.0 up
route add default gw 192.168.145.254
telnetd &

# mount nfs
mount -t nfs -o nolock,addr=192.168.143.186 -o tcp 192.168.143.186:/home/huangmingle /nfsroot

chip=xm7606v13

# load sensor ko
cd /komod
#cd /nfsroot/projects/goke/7606v1/XMIPCLinuxV100R003C00SPC020/out/$chip/ko
chmod +x load
./load $chip -i -osmem 32
```

## 四、常用三方工具调试

### tcpdump

```
tcpdump -i enp0s3 -s 0 -w ./kvs.pcap
```

### tftp

```
tftp -p -r sniffer_pre1.pcap 172.24.44.34
tftp -p -r sniffer_pre1.txt 172.24.44.34
```

### iperf

需要确保测试两端 iperf 大版本需要一样，查看版本  `iperf -v`

server:

udp: 

```sh
iperf -s -u -p 6000 -i 1
```

tcp: 

```sh
iperf -s -p 6000 -i 1
```

client:

```sh
iperf -c 10.42.0.1 -p 6000 -t 60 -i 1 -u -b 10M
```

```sh
iperf -c 192.168.0.105 -p 6000 -t 60 -i 1 -u -b 10M
```

### gprof

`gprof -b build_linux/linux_out gmon.out > gprofreport.txt`

### valgrind

```sh
valgrind --tool=memcheck --leak-check=full ./build_linux/linux_out
```
