## 抓 raw

1、按住空格上电，uboot敲命令setenv runapp 0;sa;re后，开机不跑杭研固件
2、将压缩包的程序到SD卡(注意board.toml放conf目录下)，插卡上电
3、修改环境变量并执行抓RAW程序
export LD_LIBRARY_PATH=/mnt/sdcard/:$LD_LIBRARY_PATH
cd /mnt/sdcard/;./simpletest

```
export LD_LIBRARY_PATH=/mnt/sdcard/jiuan_raw:$LD_LIBRARY_PATH
```



注意执行simpletest后会一直抓子码流RAW，所以抓完就可以ctrl C退出程序

4、抓图完成后，按住空格上电，uboot敲命令setenv runapp 1;sa;re后，自动跑杭研固件
