# 7606V1 EMMC 启动



## uboot

1）改根目录的 cfg.mk，增加 eMMC Flash 支持。

make menuconfig 勾选 Board->Flash Config->eMMC Flash Support，取消勾选 SPI Flash Support。

2）改 uboot 表格，修改 EMMC 管脚复用

| 名称       | 寄存器     | 值     |
| ---------- | ---------- | ------ |
| EMMC_CLK   | 0x100C0000 | 0x1420 |
| EMMC_CMD   | 0x100C0004 | 0x1500 |
| EMMC_DATA0 | 0x100C0008 | 0x1500 |
| EMMC_DATA1 | 0x100C000C | 0x1500 |
| EMMC_DATA2 | 0x100C0010 | 0x1500 |
| EMMC_DATA3 | 0x100C0014 | 0x1500 |
| EMMC_RST_N | 0x100C0018 | 0x1500 |
| EMMC_DS    | 0x100C001C | 0x1602 |
